# Agent Guidelines — Rakt-Connect

## Automatic Git Update Policy
After every change, bug fix, or feature addition made to this codebase:
1. Stage all modified and new project files: `git add <files>`
2. Create a clean, conventional commit: `git commit -m "<type>(<scope>): <summary>"`
3. Push updates to the remote repository: `git push origin main`
4. Confirm with `git status` that the working tree is clean.
